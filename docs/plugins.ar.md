# دليل تطوير إضافات OpenCanvas

تضيف الإضافات ميزات جديدة إلى OpenCanvas: تأثيرات للصور، وإزالة الخلفية، وتوليد تصاميم كاملة، وحزم أيقونات، وخطوطًا، أو لوحة كاملة بواجهتها الخاصة. يشرح هذا الدليل كل ما يحتاج إليه المطوّر: بنية الحزمة، وملف الوصف، والصلاحيات، وواجهة البرمجة، والعزل الأمني، والقواعد التي يجب الالتزام بها، وطريقة الاختبار والنشر.

## البدء السريع

أسرع بداية أن تنسخ مجلد المثال [`starter-tools`](../plugins/examples/starter-tools) (أدوات البداية) وتعدّله؛ فهو أصغر إضافة مفيدة، وكل أمر فيه بضعة أسطر. أو ابدأ من الصفر بهذه الخطوات:

١. أنشئ مجلدًا فيه ملفان:

</div>

`opencanvas-plugin.json`

```json
{
  "manifestVersion": 1,
  "id": "com.example.hello",
  "name": "Hello",
  "version": "1.0.0",
  "description": "Adds a greeting to the page.",
  "author": "Your name",
  "main": "main.js",
  "permissions": ["design:write"],
  "contributes": {
    "commands": [{ "id": "greet", "title": "Say hello", "titleAr": "قل مرحبًا" }]
  },
  "locales": {
    "ar": { "name": "مرحبًا", "description": "يضيف تحية إلى الصفحة." }
  }
}
```

`main.js`

```js
opencanvas.commands.register('greet', async () => {
  await opencanvas.design.insert([
    {
      type: 'text',
      x: 100,
      y: 100,
      width: 600,
      sizing: 'auto-height',
      content: { paragraphs: [{ runs: [{ text: 'مرحبًا!', style: {} }], list: 'none', indent: 0 }] },
      style: { fontFamily: 'Cairo', fontSize: 96, fontWeight: 800, color: '#7c3aed' },
    },
  ]);
});
```

<div dir="rtl" lang="ar">

٢. حزّم المجلد بالأمر التالي، فيُنشئ الملف `dist/plugins/com.example.hello-1.0.0.ocplugin`:

</div>

```bash
pnpm plugin:pack path/to/folder
```

<div dir="rtl" lang="ar">

٣. ثبّت الإضافة من **الإعدادات ← الإضافات ← تثبيت إضافة**، وراجع ما تطلبه من صلاحيات ثم وافق.

٤. افتح أي تصميم، ثم افتح لوحة **الإضافات** في الشريط الجانبي واضغط **قل مرحبًا**. يتراجع زر التراجع عن كل ما فعله الأمر دفعة واحدة.

> **بلا سطر أوامر؟** الحزمة مجرد ملف ZIP: اضغط المجلد بأي برنامج ضغط، وغيّر الامتداد إلى ‎.ocplugin‎ (أو أبقِه ‎.zip‎، فهو مقبول أيضًا).

## كيف تعمل الإضافات

يُعامَل كود الإضافة على أنه غير موثوق، لذلك لا يشغّله OpenCanvas أبدًا داخل صفحة المحرّر:

- تعمل كل إضافة في **إطار معزول** خاص بها (`<iframe sandbox="allow-scripts">` يقدّمه المسار `/plugin-sandbox`). للإطار مصدر مجهول (opaque origin)، فلا يستطيع قراءة صفحة المحرّر ولا ملفات تعريف الارتباط ولا `localStorage` ولا IndexedDB التي تُحفظ فيها تصاميمك، ولا يستطيع فتح نوافذ أو إرسال نماذج أو نقل المحرّر إلى صفحة أخرى.
- للإطار **سياسة أمان محتوى** (CSP) مستقلة: لا اتصال بالشبكة إطلاقًا ما لم تطلب الإضافة صلاحية `network` وتذكر المواقع التي تتصل بها، ويوافق المستخدم على ذلك عند التثبيت.
- تتواصل الإضافة مع المحرّر عبر **واجهة `opencanvas`** فقط، وهي ترسل رسائل إلى المحرّر. يتحقّق المحرّر من كل طلب وفق **صلاحيات** الإضافة، ويمرّ كل تعديل عبر أوامر المحرّر نفسها التي تستخدمها الواجهة، وهي أوامر موثّقة وقابلة للتراجع. ويُرفض أي عنصر غير صالح كما يُرفض عند اللصق.
- تُفحص الصور التي تعيدها الإضافة كما تُفحص الصور المرفوعة: النوع والحجم وعدد البكسلات، وتُنظَّف ملفات SVG.
- يُرسَل الكود إلى الإطار مرة واحدة فقط، وإذا أعيد تحميل الإطار أو انتقل إلى صفحة أخرى أُوقفت الإضافة.
- يبدأ الإطار أول مرة يُحتاج إليه (عند تشغيل أمر أو فتح لوحة الإضافة)، ويتوقف عند إيقاف الإضافة أو تحديثها أو إزالتها.

وفي الاختبارات إضافة تحاول الهروب من العزل (قراءة صفحة المحرّر والتخزين وIndexedDB، والاتصال بالشبكة، والتعديل دون صلاحية)، ويتحقق الاختبار من منع كل محاولة: `apps/web/e2e/plugins.spec.ts`.

## بنية الحزمة

الإضافة ملف ZIP امتداده ‎.ocplugin‎ (ويُقبل ‎.zip‎ أيضًا). يجب أن يكون في جذره الملف `opencanvas-plugin.json`، وأنت حرّ في ترتيب بقية الملفات. ويُقبل أيضًا ضغط مجلد يحتوي الإضافة (بمستوى واحد فقط).

</div>

```
my-plugin/
├── opencanvas-plugin.json   إلزامي
├── main.js                  الكود (إذا كان للإضافة أوامر أو لوحة)
├── icon.svg                 اختياري، يظهر في الإعدادات ولوحة الإضافات
├── icons/*.svg              اختياري، حزمة أيقونات
└── fonts/*.woff2            اختياري، خطوط
```

<div dir="rtl" lang="ar">

- **أنواع الملفات المسموحة:** ‎`js mjs json css html md txt svg png jpg jpeg webp woff2 woff ttf otf wasm`‎. أي نوع آخر، أو مسار مطلق، أو `..`، أو شرطة مائلة عكسية `\` يجعل الحزمة غير صالحة.
- **الأمر `pnpm plugin:pack <المجلد> [مجلد-الإخراج]`** يبني الملف ويتجاهل `README.md` و`.DS_Store` و`node_modules`.
- **يُحمَّل `main.js` بوصفه وحدة ES واحدة**، فلا يستطيع استيراد ملفات أخرى من الحزمة بمساراتها عبر `import`. اجمع الكود في ملف واحد بأداة تجميع (esbuild أو Rollup أو وضع المكتبة في Vite)، أو حمّل البيانات بالدالة `opencanvas.files.get(path)`.

## ملف الوصف

يصف الملف `opencanvas-plugin.json` الإضافة، ويُتحقَّق من كل حقل فيه قبل التثبيت.

| الحقل | إلزامي؟ | الوصف |
| --- | --- | --- |
| `manifestVersion` | نعم | دائمًا `1`. |
| `id` | نعم | معرّف بصيغة النطاق المعكوس وبأحرف صغيرة، مثل `com.example.my-plugin` (من ٣ إلى ٦٤ محرفًا). تثبيت حزمة بالمعرّف نفسه يحدّث الإضافة. |
| `name` | نعم | الاسم، حتى ٦٤ محرفًا. |
| `version` | نعم | إصدار دلالي مثل `1.2.0` أو `2.0.0-beta.1`. |
| `description` | نعم | الوصف، حتى ٤٠٠ محرف. |
| `author` | نعم | شخص أو جهة، حتى ١٠٠ محرف. |
| `homepage` | لا | رابط يظهر في الإعدادات. |
| `license` | لا | الرخصة، مثل `MIT`. |
| `icon` | لا | ملف ‎.svg‎ أو ‎.png‎ داخل الحزمة. |
| `main` | للأوامر واللوحات | ملف ‎.js‎ أو ‎.mjs‎ داخل الحزمة. |
| `panel` | لا | ‎`{ "height": 320 }`‎ لعرض واجهة الإضافة الخاصة في لوحة الإضافات (من ٨٠ إلى ١٢٠٠ بكسل). |
| `permissions` | لا | انظر [الصلاحيات](#الصلاحيات). الافتراضي: لا شيء. |
| `network` | مع `network` | أسماء المواقع التي تتصل بها الإضافة، مثل ‎`["api.example.com", "*.example.org"]`‎ (عبر HTTPS فقط، وحتى ٢٠ موقعًا). |
| `contributes.commands` | لا | حتى ٣٠ أمرًا: ‎`{ "id", "title", "titleAr"?, "context"? }`‎. |
| `contributes.iconPacks` | لا | حتى ١٠ حزم: ‎`{ "id", "name", "path" }`‎، و`path` مجلد فيه ملفات ‎.svg‎. |
| `contributes.fonts` | لا | حتى ٤٠ خطًا: ‎`{ "family", "path", "weight"?, "style"? }`‎. |
| `locales` | لا | ‎`{ "ar": { "name", "description" }, "en": { … } }`‎ يظهر حسب لغة الواجهة. |

**معرّف الأمر** (`id` داخل `commands`) وحزمة الأيقونات: أحرف إنجليزية صغيرة وأرقام وشرطات، ويبدأ بحرف أو رقم، مثل `add-title`. ويجب ألا يتكرر معرّف أمر في الإضافة نفسها.

**سياق الأمر** (`context`) يحدّد مكان ظهوره:

- `plugins` (الافتراضي): في لوحة الإضافات.
- `image`: في لوحة الإضافات وفي القائمة التي تظهر بالنقر بالزر الأيمن على صورة محدّدة (أو إطار فيه صورة). ويكون الأمر معطّلًا ما دامت لا توجد صورة محدّدة.
- `page`: في لوحة الإضافات وفي قائمة الصفحة (بالنقر بالزر الأيمن على مصغّرة الصفحة، أو بزر «…» في رأس الصفحة).

**الحقول غير المعروفة تُرفض،** وتُعرض كل مشكلة في نافذة التثبيت مع اسم الحقل، فيسهل العثور على الخطأ.

## الصلاحيات

| الصلاحية | ما تسمح به | الدوال |
| --- | --- | --- |
| `design:read` | قراءة الصفحات والعناصر والتحديد | `design.get` و`design.page` و`design.selection` و`design.select` |
| `design:write` | إضافة العناصر وتعديلها وحذفها | `design.insert` و`design.update` و`design.remove` و`design.execute` |
| `images:read` | قراءة ملفات الصور في التصميم | `images.get` |
| `images:write` | استبدال الصور وإضافة صور جديدة | `images.replace` و`images.add` (تحتاج أيضًا إلى `design:write`) |
| `network` | استخدام `fetch()` مع المواقع المذكورة في `network` | `fetch` و`WebSocket` في المتصفح |

اطلب أقل ما تحتاج إليه، فالمستخدم يرى القائمة قبل التثبيت. وأي استدعاء دون صلاحيته يُرفض بالرسالة `Permission needed: …`.

## واجهة البرمجة

كل شيء متاح عبر الكائن العام `opencanvas`، وكل الدوال تعيد وعودًا (Promises).

### معلومات

- ‏`opencanvas.version`: إصدار الواجهة (`1`).
- ‏`opencanvas.locale`: ‏`'en'` أو `'ar'`، و`opencanvas.dir`: ‏`'ltr'` أو `'rtl'`. استخدمهما لترجمة رسائل إضافتك وواجهتها.
- ‏`opencanvas.pluginId` و`opencanvas.permissions`.

### الأوامر

</div>

```js
opencanvas.commands.register('my-command', async (context) => {
  // context = { command, pageId, selection: [ids] }
});
```

<div dir="rtl" lang="ar">

- سجّل **كل** أمر مذكور في ملف الوصف عند تحميل `main.js`، وإلا ظهر الخطأ `Command "…" is not registered` عند تشغيله.
- كل التعديلات التي يجريها الأمر أثناء تشغيله تُعدّ **خطوة تراجع واحدة**.
- إذا رمى الأمر خطأً (`throw new Error('…')`) ظهرت رسالته للمستخدم، فاكتبها بلغته.
- مدة الأمر الواحد دقيقتان على الأكثر، ولا يعمل أمران في الوقت نفسه.

### التصميم

</div>

```js
const design = await opencanvas.design.get();
// { title, pageId, selection, pages: [{ id, name, width, height, background, hidden, locked, … }] }

const { page, nodes } = await opencanvas.design.page(pageId); // الصفحة الحالية إذا لم يُذكر المعرّف
const selected = await opencanvas.design.selection(); // سجلات العناصر المحدّدة

const ids = await opencanvas.design.insert([...elements], { center: false }); // على الصفحة الحالية
await opencanvas.design.update(ids, { opacity: 0.5 });
await opencanvas.design.remove(ids);
await opencanvas.design.select(ids);
await opencanvas.design.execute('node.reorder', { ids, direction: 'front' }); // أي أمر من أوامر المحرّر
```

<div dir="rtl" lang="ar">

تشغّل `design.execute` أي أمر من سجل أوامر المحرّر، وهي الأوامر الموثّقة نفسها التي تستخدمها الواجهة. تجد أسماءها ومعاملاتها في `packages/core/src/commands/builtin.ts`. مثلًا، لتغيير خلفية الصفحة:

</div>

```js
await opencanvas.design.execute('page.update', {
  id: pageId,
  patch: { background: { type: 'solid', color: '#fef3c7' } },
});
```

<div dir="rtl" lang="ar">

### الصور

</div>

```js
const { blob, width, height, mimeType } = await opencanvas.images.get(nodeId); // صورة أو إطار فيه صورة
await opencanvas.images.replace(nodeId, newBlob); // يحافظ على الموضع والحجم والقص
const placed = await opencanvas.images.add(blob); // على الصفحة (أو داخل إطار محدّد)
```

<div dir="rtl" lang="ar">

عالج البكسلات بالدالتين `createImageBitmap` و`OffscreenCanvas`، ويمكنك استخدام WebAssembly للمعالجة الثقيلة.

### الملفات والواجهة

</div>

```js
const data = await opencanvas.files.get('data/presets.json'); // ملف من حزمتك على شكل Blob
await opencanvas.ui.toast('تمّ!', 'success'); // 'info' | 'success' | 'error'
await opencanvas.ui.resize(480); // ارتفاع اللوحة بالبكسل
```

## صيغة العناصر

العناصر كائنات عادية، وتأخذ الحقول المحذوفة قيمها الافتراضية. أهمها:

</div>

```js
// شكل: rect وellipse وtriangle وstar وpolygon…
{ type: 'shape', shape: 'rect', x, y, width, height, cornerRadius: 24,
  fill: { type: 'solid', color: '#7c3aed' } }

// تعبئة متدرّجة
{ type: 'linear-gradient', angle: 135, stops: [{ offset: 0, color: '#2b1055' }, { offset: 1, color: '#db2777' }] }

// نص (عدة فقرات في مربع واحد يتمدد ارتفاعه تلقائيًا)
{ type: 'text', x, y, width, sizing: 'auto-height', align: 'center',
  content: { paragraphs: [{ runs: [{ text: 'عنوان', style: { fontSize: 96, fontWeight: 800 } }], list: 'none', indent: 0 }] },
  style: { fontFamily: 'Cairo', fontSize: 48, fontWeight: 400, color: '#111827' } }

// مسار متجهي (مساحة عرض 24×24 مثل مكتبة الأيقونات)
{ type: 'path', x, y, width: 160, height: 160, path: 'M5 12h14', viewBox: { x: 0, y: 0, width: 24, height: 24 },
  stroke: { color: '#111827', width: 2, style: 'solid', cap: 'round', join: 'round' }, fill: null }
```

<div dir="rtl" lang="ar">

- **الألوان** بالصيغة `#rrggbb` أو `#rrggbbaa`.
- **الإحداثيات** ببكسلات الصفحة بدءًا من الزاوية العلوية اليسرى.
- **خصائص مشتركة:** ‏`rotation` (بالدرجات)، و`opacity` (من ٠ إلى ١)، و`name`، و`locked`، و`hidden`.
- **المخطط الكامل** في `packages/core/src/model/types.ts` وفي [صيغة المستند](document-format.md).

## اللوحات

عند إضافة ‎`"panel": { "height": 360 }`‎ يظهر مستند الإضافة المعزول داخل لوحة الإضافات حين يضغط المستخدم **فتح**. ابنِ واجهتك بـ DOM داخل `main.js`:

</div>

```js
document.body.innerHTML = '<button id="go">إنشاء</button>';
document.getElementById('go').addEventListener('click', () =>
  opencanvas.design.insert([...]).catch((e) => opencanvas.ui.toast(e.message, 'error')),
);
```

<div dir="rtl" lang="ar">

- الأنماط المضمّنة والوسم `<style>` يعملان.
- كل استدعاء من اللوحة (خارج أمر) خطوة تراجع مستقلة، فاجمع التعديلات المترابطة في استدعاء `design.insert` واحد.
- استخدم `opencanvas.dir` لضبط اتجاه الواجهة العربية، مثل `document.documentElement.dir = opencanvas.dir`.

## حزم الأيقونات والخطوط

لا تحتاج إلى أي كود:

</div>

```json
"contributes": {
  "iconPacks": [{ "id": "arrows", "name": "Hand-drawn arrows", "path": "icons" }],
  "fonts": [{ "family": "My Brand", "path": "fonts/MyBrand-Bold.woff2", "weight": 700 }]
}
```

<div dir="rtl" lang="ar">

- **الأيقونات:** يصبح كل ملف ‎.svg‎ في المجلد أيقونة في **العناصر ← أيقوناتك** باسم الملف. تُنظَّف ملفات SVG وتُدمج أشكالها (`path` و`rect` و`circle` و`ellipse` و`line` و`polyline` و`polygon`) في مسار واحد. تبقى الأيقونات المحددة بخط (`fill="none"` مع `stroke`) كذلك، وتُملأ الأيقونات الأخرى. وتُتجاهل الأشكال التي عليها `transform`، فطبّق التحويلات على الأشكال قبل التصدير.
- **الخطوط:** ‏TTF أو OTF أو WOFF أو WOFF2، ويُتحقق من نوع كل ملف من توقيعه. تظهر تحت **خطوطك** في قائمة الخطوط، وتُضمَّن في ملفات SVG المصدَّرة.

إيقاف الإضافة يُخفي أيقوناتها وخطوطها، وإزالتها تحذفها.

## الوصول إلى الشبكة

</div>

```json
"permissions": ["network"],
"network": ["api.example.com"]
```

<div dir="rtl" lang="ar">

- لا يسمح الإطار إلا بطلبات HTTPS إلى المواقع المذكورة (إضافة إلى `blob:` و`data:`).
- تصدر الطلبات من مصدر مجهول (`Origin: null`)، لذا يجب أن يسمح الخادم بطلبات CORS.
- **لا تضع أسرارًا** (مثل مفاتيح API) في الإضافة، فأي شخص يستطيع فك ضغطها. فضّل الخدمات التي يسجّل المستخدم الدخول إليها، أو اطلب منه لصق مفتاحه في لوحة الإضافة.

## القواعد الإلزامية والحدود

هذه القواعد يفرضها OpenCanvas، فالحزمة التي تخالفها تُرفض عند التثبيت أو يُرفض الاستدعاء عند التشغيل:

1. **ملف الوصف** `opencanvas-plugin.json` في جذر الحزمة، بصيغة JSON صالحة، وبلا حقول غير معروفة.
2. **المعرّف** بصيغة النطاق المعكوس وبأحرف صغيرة، والإصدار إصدار دلالي.
3. **الأوامر واللوحة** تحتاج إلى `main`، وكل ملف مذكور (`main` و`icon` والخطوط ومجلدات الأيقونات) يجب أن يوجد في الحزمة بالامتداد الصحيح.
4. **معرّفات الأوامر** فريدة داخل الإضافة، وكل أمر مذكور يجب أن يُسجَّل في الكود.
5. **المواقع في `network`** تحتاج إلى صلاحية `network`.
6. **كل استدعاء** يجب أن تغطيه صلاحية معلنة.
7. **الملفات** من الأنواع المسموحة فقط، بمسارات نسبية داخل الحزمة.
8. **العناصر والصور** التي تضيفها الإضافة تخضع للتحقق نفسه الذي يخضع له اللصق والرفع.

| الحد | القيمة |
| --- | --- |
| حجم الحزمة | ٢٥ ميغابايت (و٦٠ ميغابايت بعد فك الضغط، و١٥ ميغابايت للملف الواحد، و٤٠٠ ملف) |
| الأوامر / حزم الأيقونات / الخطوط | ٣٠ / ١٠ / ٤٠ |
| مهلة بدء التشغيل | ١٥ ثانية |
| مدة الأمر الواحد | دقيقتان |
| الاستدعاءات المتزامنة | ٦٤ |
| العناصر في استدعاء `design.insert` واحد | ١٠٠٠ |

## إرشادات لإضافة جيدة

- **اجعل كل أمر خطوة واحدة ذات معنى،** لأنه يُتراجع عنه دفعة واحدة.
- **ادعم اللغتين** عبر `titleAr` و`locales.ar` و`opencanvas.locale`، واكتب رسائل الأخطاء بلغة المستخدم.
- **اعمل دون اتصال** حين يمكن، ووضّح في الوصف متى تحتاج إلى الشبكة ولماذا.
- **لا تجمع بيانات** دون أن تذكر ذلك صراحة في الوصف.
- **ارفع رقم الإصدار** مع كل تحديث، ليرى المستخدم التغيير في نافذة المراجعة.
- **أعطِ رسالة واضحة** عندما ينقص شيء، مثل: «حدّد شكلًا أولًا».

## الاختبار وتصحيح الأخطاء

- حزّم الإضافة بالأمر `pnpm plugin:pack` وثبّتها من **الإعدادات ← الإضافات**. تثبيت حزمة بالمعرّف نفسه يحدّثها، وتعرض نافذة المراجعة تغيّر الإصدار.
- الأخطاء التي يرميها الأمر تظهر رسالةً في المحرّر، وتظهر رسائل `console.log` من الإضافة في أدوات المطوّر في المتصفح (اختر إطار الإضافة في وحدة التحكم).
- تعرض نافذة التثبيت كل مشكلة في ملف الوصف مع اسم حقلها.
- يمكنك إيقاف الإضافة مؤقتًا أو إزالتها نهائيًا من **الإعدادات ← الإضافات**.
- أمثلة على الاختبارات الآلية: يثبّت الملف `apps/web/e2e/plugins.spec.ts` الأمثلة بأداة Playwright ويتحقق مما تفعله.

**رسائل خطأ شائعة:**

| الرسالة | السبب والحل |
| --- | --- |
| `The plugin manifest is not valid` | في ملف الوصف حقل خاطئ أو ناقص؛ تعرض نافذة التثبيت اسمه. |
| `The plugin package is incomplete` | ملف مذكور في ملف الوصف غير موجود في الحزمة أو امتداده خاطئ. |
| `File type not allowed in plugins` | في الحزمة ملف من نوع غير مسموح؛ احذفه. |
| `Permission needed: …` | استدعاء دون صلاحيته؛ أضفها إلى `permissions`. |
| `Command "…" is not registered` | الأمر مذكور في ملف الوصف ولم يُسجَّل بالدالة `commands.register`. |
| `The plugin did not start in time` | استغرق تحميل `main.js` أكثر من ١٥ ثانية، أو فيه خطأ يمنع تشغيله. |

## التحديث والنشر

- **التحديث:** ارفع رقم `version` وثبّت الحزمة الجديدة بالمعرّف نفسه؛ تحلّ النسخة الجديدة محلّ القديمة وتُفعَّل الإضافة.
- **النشر:** شارك ملف ‎.ocplugin‎ مباشرة (مثلًا في إصدارات GitHub)، واذكر في الوصف ما تفعله الإضافة وما تطلبه من صلاحيات.
- **الأمثلة الرسمية** تحت رخصة MIT، فانسخ أيًّا منها نقطةَ بداية لإضافتك.
